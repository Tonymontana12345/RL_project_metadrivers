# MetaDrive 자율주행 강화학습 프로젝트 2차 (Generalization)

1차 프로젝트에서 확장하여, **복잡한 도로 구조(TSCO)와 다양한 트래픽 환경**에서의 주행 능력 학습 및 **일반화 성능(Generalization)** 향상을 목표로 합니다.

## 📋 프로젝트 목표

1.  **복잡한 맵 적응**: 단순한 도로가 아닌 교차로(T), 직선(S), 곡선(C), 회전교차로(O)가 복합된 **TSCO** 맵에서 주행을 학습합니다.
2.  **일반화 성능 극대화**:
    *   **다중 시드 학습**: 난이도별로 구성된 6개의 훈련 시드에서 학습하여 특정 맵에 과적합되는 것을 방지합니다.
    *   **랜덤 맵 테스트**: 학습 때 보지 못한 무작위 블록 조합의 맵에서도 주행 가능한지 검증합니다.

---

## 🚀 학습 및 실행 가이드

TD3 알고리즘을 사용하여 `TSCO` 맵 또는 다중 시드 환경에서 학습을 진행합니다.

### 1. 학습 시작 (Training)

**단일 맵(TSCO) 집중 학습**
```bash
# TSCO 맵 구조에서 집중 학습 (1M steps)
python train.py --mode fixed --algorithm td3
```

**다중 시드(Multi-Seed) 일반화 학습**
```bash
# 난이도가 섞인 6개 시드에서 학습 (800k steps)
python train.py --mode multi --algorithm td3
```

### 2. 평가 (Evaluation)

**기본 성능 평가**
학습된 모델을 테스트 시드(Test Seeds)에서 평가합니다.
```bash
python evaluate.py --model models/td3_tsco_map_500k.zip --episodes 20
```

**랜덤 맵 조합 평가 (Zero-shot)**
`T, S, C, O` 블록을 무작위로 섞어 만든 새로운 맵 10개에서 모델을 테스트합니다.
```bash
python evaluate_random_maps.py --model models/td3_tsco_map_500k.zip --num-maps 10
```

## ⚙️ 주요 변경 사항 (vs 1차)

| 항목 | 1차 (Baseline) | 2차 (Advanced) | 비고 |
| :-- | :-- | :-- | :-- |
| **맵 구조** | 단순/고정 | **TSCO** (복합 구조) | 교차로, 로터리 등 포함 |
| **트래픽 밀도** | 0.1 (낮음) | **0.15** (중간) | 더 많은 장애물 차량 |
| **학습 시드** | 1개 (1000) | **6개** (난이도 혼합) | 과적합 방지 |
| **관측(LiDAR)** | 240개 레이저 | **72개** 레이저 | 차원 축소로 학습 효율화 |
| **보상 함수** | 기본 설정 | **최적화됨** | 주행(+1.5), 속도(+0.3), 페널티 완화 |

## 🔬 실험 내용

### 학습 데이터셋 구성 (Train Seeds)
다양한 난이도의 맵을 섞어 학습 데이터의 다양성을 확보했습니다.
*   **쉬움**: 6339 (직선 위주), 8576
*   **중간**: 1409, 4806
*   **어려움**: 2824, 5506 (급커브, 복잡한 교차로)

### 평가 방법
1.  **Test Seeds**: 학습에 사용하지 않은 고정된 시드 5개(`2679`, `3286` 등)에서 평가.
2.  **Random Maps**: 실행 시마다 생성되는 완전히 새로운 맵 구조에서 평가하여 진정한 자율주행 능력 검증.
